CS F214 — Logic in CS — Assignment 1, Part A

A C11 implementation of the propositional-logic parse-tree tasks, with Task 6 output, efficiency, and memory analysis. The program also accepts DIMACS CNF files so the implementation can be applied to SAT benchmark instances.

Requirements

  • GCC or another C11-compatible compiler
  • GNU Make
  • Doxygen (only needed to generate the API reference)

No third-party C libraries are required.

Build

Run from the project root:

make

Alternatively:

gcc -std=c11 -Wall -Wextra -Wpedantic -O2 src/logic_assignment.c -o logic_assignment

Run an infix formula

./logic_assignment

Enter a formula when prompted, for example:

((P*Q)>~R)

The operators are:

Symbol Meaning Truth condition
~ NOT ~P is true exactly when P is false.
+ OR P+Q is true when at least one operand is true.
* AND P*Q is true only when both operands are true.
> Implication P>Q is false only when P is true and Q is false.

Atom names can contain letters, digits, and underscores, and must start with a letter or underscore. Spaces are ignored between tokens. Fully parenthesized formulas are recommended. Invalid parentheses and malformed tokens produce an Invalid formula: diagnostic.

The program writes analysis_report.html in the current working directory. Running it from the project root replaces the report file included in this submission.

Run a DIMACS CNF file

./logic_assignment --dimacs examples/sample.cnf

The equivalent positional form is also supported:

./logic_assignment examples/sample.cnf

The importer reads a DIMACS p cnf V C header, integer literals, and 0 clause terminators. Positive literals represent variables, negative literals represent negated variables, and lines beginning with c are comments. Clauses are represented as OR subtrees and the complete CNF formula as an AND tree. The subtrees are built in balanced form to keep their height relatively small.

examples/sample.cnf is a small illustrative instance with three declared variables and three clauses. It is not the complete SAT Competition 2002 dataset.

SAT Competition 2002 benchmark dataset

The assignment refers to the SAT Competition website and the SAT 2002 benchmark collection. The archive is not bundled because it is a separate, large dataset. Download and extract it from the official/archive links, then pass a selected .cnf file to the importer:

  • SAT Competition: https://satcompetition.github.io/
  • SAT 2002 benchmark index: https://satisfiability.org/competition/2002/submittedbenchs.html
  • SAT 2002 benchmark ZIP: https://satisfiability.org/competition/2002/sc2002benchs.zip
  • DIMACS CNF format explanation: https://jix.github.io/varisat/manual/0.2.0/formats/dimacs.html

Example:

./logic_assignment --dimacs examples/sample.cnf

The program is a formula/tree processor, not a dedicated SAT solver. For more than 16 distinct variables, complete truth-table printing is skipped because a truth table requires 2^v rows.

Doxygen API documentation

From the project root, generate the API reference with either command:

doxygen Doxyfile
xdg-open docs/api/html/index.html

or:

make docs
xdg-open docs/api/html/index.html

Open docs/api/html/index.html after generation. The hand-authored overview and algorithm-complexity page is docs/index.html. The run-specific measured output is saved to analysis_report.html.
