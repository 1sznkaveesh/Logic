Observations

  • Every traversal and both height algorithms visit each node once, so they take O(n) time.
  • Recursive versions use the call stack: depth h + 1. Iterative versions use an explicit stack or queue instead, which is why overflow of the call stack is avoided.
  • Iterative postorder with two stacks needs O(n) extra memory; the other traversals need only O(h).
  • Iterative height (BFS) needs memory for the widest level of the tree.
  • For CNF files the clauses and the literals inside each clause are joined into balanced trees, so h is about log2 n and recursion stays shallow.
  • The truth table has 2v rows and each row costs one evaluation of O(n), so it is only produced for up to 16 variables.
